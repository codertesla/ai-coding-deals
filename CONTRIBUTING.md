# Contributing / 参与贡献

Thanks for helping keep **AI Coding Deals** accurate! 感谢帮助保持本仓库的准确。

This repo lives and dies by **accuracy and freshness**. Even a one-line fix (a price change, an expired discount) is hugely valuable.

本仓库的核心价值是**准确与及时**。哪怕只改一行(价格变动、折扣过期)都非常有价值。

## What you can contribute / 你可以贡献什么

- ✏️ **Fix outdated info** — a price, plan, or discount changed / 修正过时信息
- ➕ **Add a new tool** / 新增工具
- 🏷️ **Add a discount, free tier, or referral/promo** / 补充折扣、免费额度、邀请/促销
- 🗑️ **Flag a dead/incorrect entry** / 标出失效或错误条目

## How to submit / 如何提交

1. Open an [issue](../../issues/new/choose) for quick reports, or a PR to edit directly.
   快速反馈可开 Issue,直接修改请发 PR。
2. **Always include / 务必附上:**
   - 🔗 **Official source link** (vendor pricing/changelog page) / 官方来源链接
   - 📅 **Date you verified it** / 你核实的日期
   - ⏳ **Expiry date** for time-limited discounts / 限时折扣的有效期

## Style rules / 格式规则

- Keep entries in the **same table format** as the README. / 保持与 README 相同的表格格式。
- Pricing: write the number only if you confirmed it on the official page **today/recently**. If unsure, write `see site` / `见官网`. / 拿不准的价格写"见官网",不要瞎填。
- Update **both** `README.md` (English) and `README.zh-CN.md` (中文) when possible. If you can only do one language, that's fine — note it in the PR and a maintainer will sync. / 尽量同步更新中英两个文件;只改一个也可以,请在 PR 说明。
- Bump the **"Last verified"** date if you did a broad review. / 做了大范围核实请更新"最后核实"日期。

## Referral / affiliate links / 邀请与返利链接

Referral links are allowed **only if** the deal is genuinely good for the user (same or better than the public price). Mark them clearly. Spammy or worse-than-public links will be rejected.

仅当对用户确实有利(不劣于公开价)时才接受邀请/返利链接,且必须明确标注。垃圾链接或劣于公开价的链接会被拒绝。

## Not accepted / 不接受

- Unverifiable claims with no source / 无来源、无法核实的说法
- Tools that are clearly abandoned / 明显停止维护的工具
- Pure self-promotion without real value / 纯自我推广、无实际价值
