## Free & Zero-Budget AI Coding Stack ($0 / BYOK)

You can run a production-capable AI coding workflow on a **$0 monthly software budget** by combining open-source harnesses with free inference tiers:

- **Zero-Key Ad-Supported Agent:** [Freebuff](https://freebuff.com/) provides a free CLI (`npm install -g freebuff`), Web, Desktop, and Chat harness routing to **DeepSeek V4.1 Flash**, Kimi, and MiniMax with no credit card or API key. *(Operated by the [Codebuff](https://www.codebuff.com) team as a standalone free product.)*
- **Open-Source Clients + Local Models ($0):** Pair [Aider](https://aider.chat), [Continue.dev](https://www.continue.dev), [Cline](https://cline.bot), or [OpenCode](https://opencode.ai) with local models via Ollama for zero token spend and complete local code privacy.
- **Included in Existing Free Accounts:** [OpenAI Codex](https://openai.com/codex) (bundled with ChatGPT Free/Plus) and [GitHub Copilot Free](https://github.com/features/copilot) (2,000 completions/month).
- **Standalone IDE Free Tiers:** [Google Antigravity](https://antigravity.google) (free inline Tab completions + recurring 5-hour agent compute pools) and [Cursor](https://cursor.com) (Free tier, capped).
- **Free OpenAI-Compatible API Endpoint (NVIDIA NIM):** [NVIDIA NIM](https://build.nvidia.com/) (`base_url="https://integrate.api.nvidia.com/v1"`) issues a single API key covering a broad [open-weight catalog](https://build.nvidia.com/models) at up to ~40 RPM (phone OTP required; rate-limited for prototyping, no SLA). **Recommended baseline model:** `nvidia/nemotron-3-super-120b-a12b` for fast, clean `message.content` responses.
- **90-Day Multi-Model Trial Pool (Tencent Cloud):** New users claiming the trial on [Tencent Cloud AI Model Square](https://curl.qcloud.com/PN0cvBnI) receive **1M free tokens per model** across all listed LLM and multimodal endpoints for 90 days, plus optional **¥28/mo for 35M tokens** on Hunyuan HY3.
- **More Free LLM API / BYOK Endpoints:** vendor-published free tiers across SiliconFlow, Alibaba Cloud Model Studio, Volcano Ark, Cloudflare Workers AI, ModelScope, Telnyx and more — see [Free LLM API & BYOK Endpoints](#free-llm-api--byok-endpoints) for quotas and access requirements.

## 7 Rules to Cut AI Coding & Token Spend

1. **Audit credit burn multipliers, not just sticker price.** A $20/mo plan is rarely a flat rate: Kiro bills Opus 4.8 at **2.2×** vs. Qwen3 Coder Next at **0.05×** (a 44× spread), while Copilot, Antigravity, and Cursor deduct from credit or compute pools on frontier models.
2. **Route by task difficulty.** Bind fast, low-cost models (DeepSeek V4.1 Flash, GLM-5.3 Flash, Haiku, Gemini Flash) to inline completions, unit tests, and boilerplate. Save Opus, Sonnet, or o-series reasoning models strictly for cross-module architecture and root-cause debugging.
3. **Exploit DeepSeek V4.1 Flash off-peak windows.** Run daily coding through **Freebuff (free)** or **OpenCode Go ($10/mo, $100 Flash allowance)**. When billing direct API tokens (`deepseek-flash` on the official API, `deepseek-v4.1-flash` on Go), batch heavy jobs outside Mon–Fri 01:00–04:00 and 06:00–10:00 UTC to cut token cost by **50%**.
4. **Decouple the agent harness from the inference provider.** Open-source clients (**Aider, Cline, Continue.dev, OpenCode, Roo Code**) let you swap underlying API providers in seconds—routing to Tencent Model Square (1M free tokens/model), NVIDIA NIM ($0), or local Ollama models with zero vendor lock-in.
5. **Chain new-user credit grants before subscribing.** Claim WorkBuddy's **2,000 invite credits plus onboarding task credits (cited ceiling 3,600)**, Tencent Model Square's **90-day 1M-token pools**, Codebuff's **500 signup credits**, and SuperGrok's **7-day trial** to benchmark real repository workloads before committing to a monthly seat.
6. **Switch proven tools to annual billing.** Once an IDE or CLI agent survives a 30-day workflow test, switching from monthly to annual billing locks in a **15%–20% discount**.
7. **Re-benchmark every quarter.** Vendor quotas, free tiers, and model multipliers shift every 60–90 days. A quarterly 15-minute audit prevents paying legacy seat prices for commodities that are now free upstream.
